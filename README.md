# Evaluación de tratamiento de datos personales (v2)

Aplicación web en **React + Vite + Tailwind CSS** para determinar si un tratamiento de datos personales califica como **gran escala**.

## Funcionalidades
- Pantalla de inicio.
- Verificación de calificación directa.
- Formulario de evaluación por puntaje.
- Resultado final y reinicio.
- Exportar evaluación a PDF.
- Guardar evidencia en localStorage.
- Historial de evaluaciones guardadas.
- Panel admin para editar preguntas y puntajes.

## Requisitos
- Node.js 18+
- npm 9+

## Ejecutar en local
```bash
npm install
npm run dev
```

Luego abre la URL que muestra Vite (normalmente `http://localhost:5173`).

## Build de producción
```bash
npm run build
npm run preview
```
